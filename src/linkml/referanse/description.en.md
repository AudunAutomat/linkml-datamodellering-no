The reference domain contains `referansemodell`, a teaching schema that demonstrates all the main patterns used in this repository: container class, global slots, import hierarchy, URI mapping, multilingual strings, mandatory/recommended/optional classification (obligatorisk/anbefalt/valgfri) and linking instead of inlining.

The schema also exists in medallion variants (`referansemodell-bronze`, `-silver`, `-gold`) that illustrate what is required at each policy level — see the policy hierarchy in CLAUDE.md.

**Typical user:** New developers learning LinkML modeling in this repository. The schema is not used in production.
