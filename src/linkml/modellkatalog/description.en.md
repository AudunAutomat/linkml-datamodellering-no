The model catalog domain contains metadata about information models from several public bodies, modeled according to ModelDCAT-AP-NO and published to the [national model catalog](https://data.norge.no/informationmodels) (Felles modellkatalog).

Each organization has its own subdirectory with production data: `brreg-modellkatalog`, `digdir-modellkatalog`, `kartverket-modellkatalog`, `ksdigital-modellkatalog`, `novari-modellkatalog` and `skatteetaten-modellkatalog`.

**Typical user:** Model administrators in the respective organizations, and external users searching for information models via Felles modellkatalog.
