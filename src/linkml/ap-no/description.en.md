The AP-NO profiles are the Norwegian application profiles of central W3C and EU vocabularies, adapted to the Norwegian public sector and modeled in LinkML according to the specifications from the Norwegian Digitalisation Agency (Digitaliseringsdirektoratet, Digdir).

The domain contains seven profiles: `common-ap-no` (common base classes and data types for the other profiles), `dcat-ap-no` (datasets, data services and distributions), `dqv-ap-no` (data quality), `skos-ap-no` (concepts), `xkos-ap-no` (classifications and code lists), `cpsv-ap-no` (public services) and `modelldcat-ap-no` (information models). See [Digdir's specifications](https://informasjonsforvaltning.github.io/) for each individual profile.

**Typical user:** Developers and modelers who need to import one or more AP-NO profiles into their own domain models. The profiles have no `tree_root` class and are not intended for direct use as standalone schemas.
